CSV requirements and AI setup prompt

Required structure: one event per row; a session identifier column named session_id or user_session_id; a parseable timestamp; and at least one supported activity flag. Timespent_seconds is recommended for duration rings. Supported flags: Read, Video_watch, Quiz, Assessment, See_Errors, Annotate, Highlight, View_Annotation, View_Highlight. Flags should be 1 when that row represents the activity, otherwise 0. Each row should represent one event, timestamps should use a consistent timezone/format, and session IDs must uniquely identify a session.

Sessions with timestamp spans over 6 hours are excluded. Each remaining session is treated independently. Uploading a CSV recalculates the profiles and findings from that file. Duration is assigned to the 1%-wide bin containing each event timestamp, which is an approximation if duration spans across bins.

1 · Activity over session time

Concentric rings · angle = session progress (0–100%) · color intensity = recorded duration summed across retained sessions in each 1%-wide progress bin. A pooled 95th-percentile cap controls color intensity; the final 99–100% bin is white.

White ring segments mark the final 99–100% bin, excluded from the color scale. Select an inference to highlight its activity ring and time interval.
Bins 0–98 use a pooled 95th-percentile cap. Values at or above the cap share the maximum color; exact totals remain available on hover. The final 99–100% bin is white and excluded.

2 · Directed transitions over session time

Six source-activity panels, each with six destination lines. Each point is the mean transition count per session in a window covering 1% of that session's duration. Each transition's destination falls in the corresponding 1%-wide progress bin; transitions with source-destination gaps longer than 1% of the session are excluded.

3 · Inference driver

Plain-language observations detected directly from the visual profiles. Click a finding to highlight where it appears in the charts.

Interpretation and safeguards

Inference status: These cards describe visible patterns in smoothed aggregate profiles. They are descriptive prompts for instructor exploration, not claims about learning effectiveness.
Transition rule: transitions are collapsed across excluded interface events within the same session, but the primary transition profile includes only source/destination pairs with elapsed gaps ≤1% of that session duration. The destination timestamp determines the event's session-relative position.
Value scaling: chart intensity is scaled for visual comparison; statistical comparisons use unscaled counts. Event count is not the same as time spent or cognitive engagement. Duration-based activity estimates are available in the data exports but should be interpreted only after validating the platform's duration semantics.
